1. **FreeMoCap invocation:** Installer may require specific environment. If subprocess fails, fallback needed (stub BVH generator for testing).

4. **iFrame sandboxing:** If Palm Command needs to cross-origin fetch Shadow Broker, may need CORS or proxy layer.

5. **GPU inference:** FreeMoCap on CPU is slow. If slow, may need to limit queue depth or warn user.
